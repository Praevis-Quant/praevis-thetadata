# Endpoint coverage

Generated by `tools/generate_endpoints.py` from the pinned 1.0.17 inventory and
[`status.json`](status.json); do not edit by hand. This table replaces
per-clause requirement matrices for generated endpoints
([lighter process](../architecture/performance-plan.md#f-process-simplification)).

The value check compares our columnar decoder with the legacy decoder, and runs the
request through the Python package: step F for options (`live_p0 option-checks`,
`bench/p1/option_checks.py`), and `live_p0 entitlements --set stock-index-rate` with
`bench/p1/stock_index_rate_checks.py` for stocks, indices, calendar and interest rate.
Flat files are bounded probes only. The run named is the Rust run; "Python OK" is
from its matching Python run (`opt-checks-py-001` for the option checks).

The FREE column is the one-time entitlement map: one request per endpoint family,
classified by a person from the private report. The PRO account column holds the
runs on the user's account (options PRO; stocks and indices FREE): the approved
options PRO map, every option RPC once, and the approved stock, index, calendar and
interest-rate run. Only the classification and gRPC code are committed. A named tier
is the tier the service said is required. *Gated* means a probe needs explicit
approval (it could start the vendor's generation of a very large file).
*Column kinds registered* means the result's column types come from
[`schemas.json`](schemas.json), observed in the runs named, so a column that is null
throughout a response keeps its type ([ADR-0009](../adr/0009-market-data-values-and-schema.md)).
*Uncertain* marks a classification the evidence does not settle. Endpoints that
were not probed are not inferred from their family.

**Subscription required** is the lowest tier the evidence establishes, per product:
the tier the service named when it refused, or FREE where a FREE tier of that product
was entitled. Anything else is *unknown*, never inferred from the RPC's family.
Calendar and interest-rate refusals name a tier but not a product.
